# Football Insider ⚽

A modern, responsive football transfer and news website focused on a premium editorial experience.

> **Important:** This is an independent project and is not the official website of Fabrizio Romano. The project is designed to publish original content and, where integrations are used, clearly attribute and link to the original external sources.

## ✨ Current Features

- Premium football-news homepage
- Breaking-news ticker
- Transfer Centre with deal-status labels
- Latest football news section
- X/social update layout ready for API integration
- YouTube/video section ready for API integration
- Player directory foundation
- Club directory foundation
- Responsive desktop, tablet and mobile layout
- Original project branding and favicon
- Lightweight HTML/CSS/JavaScript architecture

## 🛠️ Local Development

No build step is currently required. Open `index.html` in a browser or serve the folder with any static web server.

For example:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## 🌐 Deployment

The project can be deployed as a static site using GitHub Pages, Render Static Sites, Netlify, Vercel, or another static hosting provider.
